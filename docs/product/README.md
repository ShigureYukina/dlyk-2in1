## 阅读路径

**3 分钟版**（快速了解产品能力）：

1. 本导览的作品清单表 → 2. 治理专项 PRD 的「三、需求项清单与优先级」+「六、效果验证」→
3. 打开交互原型，按下方演示动线走一遍。

**深读版**（面试官/同行评审视角）：

1. 线索 PRD —— 看需求如何从业务场景推到功能分级与验收标准；
2. 治理专项 PRD —— 看资源有限时如何定优先级、如何对待未达成目标（70% 目标、实测 50%）；
3. CRM 竞品分析 —— 看「竞品有、我们没有」时怎么论证做不做；
4. 网关 PRD —— 看一个平台型产品的定位、边界与规则设计；
5. 网关竞品分析 —— 看差异化主张如何落在可防守的能力点上。

## 原型 3 分钟演示动线

打开 [原型-线索管理与客户转换.html](原型-线索管理与客户转换.html)，建议顺序：

1. **帧①线索列表**：右上打开「标注模式」（界面出现编号标注，对应帧下方的需求要点）；
2. 在列表第 1 行点「详情」→ **帧②**看跟进记录时间线，现场添加一条跟进；
3. 回列表点第 1 行「转客户」（或 **帧③**）→ 确认弹窗：看实时查重提示 → 快速连点两次「转 换」→ 触发**幂等拦截**（30 秒窗口）；
4. 正常提交一次 → 列表顶部出现「后台处理中」横条 → 约 2 秒变完成，该行状态变绿、按钮禁用；
5. **帧⑤异常态与回退**：依次点六张卡的「演示」（幂等 / 分布式锁 / 唯一索引 / 重试 / ES 回落 / 同步回退开关）。

> 原型为单文件零依赖 HTML，界面元素与 `dlyk-front` 真实实现对齐；每帧下方「需求要点」标注了对应 PRD 章节。
